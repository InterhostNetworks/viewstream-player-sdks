# ערכת הפיתוח לנגן HTML5 של ViewStream (HTML5 Player SDK)

הערכה מאפשרת להציב את נגן ה-HTML5 של ViewStream באתר שלכם ולעצב את המראה שלו. אתם כותבים קובץ CSS אחד ורואים אותו על
הנגן האמיתי, עם שידור חי, סרטון ופרסומות, במחשב שלכם.

## מתחילים בשתי דקות

צריך Python 3 ודפדפן עדכני. אין צורך בחשבון.

```bash
cd viewstream-html5-player-sdk-1.1.0
python3 serve.py
```

פתחו את <http://localhost:8000>, ערכו את `theme/my-theme.css` ורעננו את הדף.

סביבת העבודה כוללת ערוץ חי לדוגמה עם לוח שידורים, סרטון לדוגמה עם כתוביות ופרקים, ופרסומות VAST. הכפתורים בדף
מחליפים תוכן, שפה, מראה כהה או בהיר, ורוחב של טלפון, טאבלט או מחשב. הכפתור **Keep controls visible** משאיר את הפקדים
גלויים בזמן העבודה. הכפתור **Without my theme** מציג את מראה ברירת המחדל של הנגן.

**כדי לראות את הערוץ שלכם,** הזינו ב-`kit.config.js` את ה-tenant (ה-slug של הארגון שלכם) ואת הערוץ. אז מופיע הכפתור
**My channel**.

סביבת העבודה עצמה כתובה באנגלית. הנגן שבתוכה מוצג בעברית כשבוחרים **Hebrew (RTL)**.

אותו שרת מריץ גם שני כלים נוספים:

- כלי התצורה, בכתובת <http://localhost:8000/configurator.html>: בוחרים בטופס את התוכן, המראה והתכונות, רואים אותם על
  הנגן, ומעתיקים את מפתחות התצורה, את תגית הנגן או את ה-iframe.
- הדוגמאות, בכתובת <http://localhost:8000/examples/>: עמודים קטנים ועובדים של iframe, תגית נגן, ערוץ חי, אפשרויות
  סרטון, תצורת נגן, פרסומות, אירועים ואריחי תצוגה מקדימה. כל עמוד מציג את הקוד של עצמו.

## מה יש בערכה

| נתיב | מה זה |
|---|---|
| `index.html`, `serve.py` | סביבת העבודה והשרת המקומי הקטן שלה |
| `theme/my-theme.css` | **הקובץ שבו אתם עובדים** |
| `kit.config.js` | אופציונלי: ה-tenant והערוץ שלכם |
| `configurator.html` | כלי התצורה: בונים תצורת נגן ואת קוד ההטמעה שלה |
| `examples/` | עמודי דוגמה עובדים, מוכנים להעתקה |
| `docs/TENANT-AND-CONFIG.he.md` | **מתחילים כאן עם התוכן שלכם:** חיבור ה-tenant, ואיפה מגדירים כל תכונה |
| `docs/OPTIONS.he.md` | **כל היכולות והאפשרויות של הנגן:** תצורה, מאפייני התגית, מקלדת ואירועים |
| `docs/THEMING.he.md` | צבעים, גדלים, שמות מחלקות (classes) ומצבי הנגן |
| `docs/EMBED.he.md` | איך מציבים את הנגן בעמוד, האירועים שלו, ואיך פועלות הפרסומות |
| `reference/vs-vjs.reference.css` | קובץ ה-CSS של הנגן עצמו, לקריאה בלבד, לחיפוש שמות מחלקות |
| `sample-media/` | הווידאו של הערוץ החי לדוגמה |
| `LICENSE` | תנאי השימוש בערכה (באנגלית) |

כל מסמך קיים גם באנגלית, באותו שם בלי הסיומת `.he`.

קוד הנגן אינו חלק מהערכה. סביבת העבודה טוענת אותו מ-`player.viewstream.co.il`, אותו מקום שממנו האתר שלכם יטען אותו,
כך שאתם תמיד מעצבים על הנגן העדכני.

## לא צריכים עיצוב מותאם אישית?

לנגן יש סקינים מוכנים, שמוצגים בכתובת <https://player.viewstream.co.il/skins/>. איש הקשר שלכם ב-ViewStream יכול להגדיר
לכם אחד מהם, או ראו את `data-skin` במסמך `docs/EMBED.he.md`.

## מה אפשר לשנות

- צבעים, גופנים, גדלים, מרווחים, פינות וצלליות
- סמלים, כפתורים ותפריטים
- כרטיס התוכנית, פס ההתקדמות וסגנון הכתוביות
- המראה של סרגל הפרסומת: כפתור הדילוג, הקישור "Learn more" והספירה לאחור

## מה נשאר באחריות ViewStream

השאירו את הדברים הבאים כפי שהם. אם העיצוב שלכם דורש שינוי באחד מהם, פנו אלינו.

- **קוד הנגן ואופן הניגון:** איכות מסתגלת, התנהגות השידור החי והחזרה אחורה, התאוששות מתקלות, פורמט הסטרימינג ולוגיקת
  הפרסומות. אל תעתיקו ואל תשנו את ה-JavaScript או את ה-CSS של הנגן, ואל תארחו עותק משלכם.
- **אילו כפתורים ותכונות פעילים, ותגיות הפרסום:** אלה נקבעים בתצורת הנגן שלכם ב-ViewStream Studio.
- **דיווחי הצפייה:** בעמודי הייצור שלכם הם חייבים להישאר פעילים. הם כבויים רק בסביבת העבודה הזו, כדי שעבודת העיצוב לא
  תיספר בסטטיסטיקות שלכם.

## לפני שמחזירים את העיצוב

בדקו כל סעיף בסביבת העבודה, וגם במכשירים אמיתיים:

- [ ] שתי השפות שבהן אתם משתמשים: שום דבר אינו הפוך בכיוון הלא נכון ושום דבר אינו חתוך
- [ ] טלפון 360, טאבלט ומחשב: כל הכפתורים נכנסים בשורה אחת
- [ ] שידור חי: כרטיס התוכנית, פס ההתקדמות, כפתור החזרה לשידור החי וסימון השידור החי ברורים
- [ ] סרטון: הכתוביות קריאות על תמונה בהירה ועל תמונה כהה, והפרקים והתמונות הממוזערות נראים נכון
- [ ] פרסומות: כפתור הדילוג, הקישור "Learn more" והספירה לאחור ברורים, עם כפתור דילוג ובלעדיו
- [ ] המקלדת עובדת: טבעת המיקוד מופיעה על כל פקד (מקש Tab)
- [ ] מסך מלא, בדפדפן במחשב וגם באייפון ובטלפון אנדרואיד אמיתיים. אייפון עשוי להציג את הפקדים שלו במסך מלא, ולכן
      בדקו איך העיצוב שלכם נראה שם
- [ ] מראה כהה ומראה בהיר, אם אתם משתמשים בשניהם

## איך מחזירים את העיצוב

שלחו את `theme/my-theme.css`, יחד עם הגופנים והתמונות שהוא משתמש בהם, לאיש הקשר שלכם ב-ViewStream. אנחנו בודקים אותו
ומפרסמים אותו כסקין שלכם, ואז הוא פועל בכל הנגנים שלכם, כולל iframe ועמודים מתארחים. אל תציבו אותו בעצמכם בעמודי
הייצור.

ארחו גופנים ותמונות בדומיין שבשליטתכם, ב-HTTPS ועם CORS פתוח, או שלחו אותם אלינו יחד עם העיצוב.
