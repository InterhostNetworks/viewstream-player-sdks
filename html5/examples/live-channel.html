Live channel

A live channel with the programme card, the programme seek bar, start-over, previous and next programme, and the back-to-live button. The player finds your tenant's configuration and programme guide from data-tenant and the stream address.

No tenant is set in kit.config.js, so this plays the kit's sample channel from serve.py. The code below shows the tag for your own channel.

The sample live channel runs only in the downloaded kit. Type your tenant and channel in the form to play your own channel here. The code below shows the tag.
