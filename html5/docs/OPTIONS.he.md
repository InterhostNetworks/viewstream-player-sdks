# היכולות והאפשרויות של הנגן

זהו המסמך המלא של נגן ה-HTML5. את רוב האפשרויות אפשר לנסות
ב[כלי התצורה המקוון](https://player.viewstream.co.il/#configurator).

שמות המפתחות, המאפיינים והערכים נכתבים תמיד באנגלית, בדיוק כפי שהם מופיעים כאן.

## מאיפה מגיעות ההגדרות

מהחזק לחלש:

1. **העמוד:** מאפייני `data-*` ו-`data-options` שעל תגית הנגן
2. **תצורת הנגן:** נקבעת ב-ViewStream Studio ← נגנים, ומגיעה לצופים תוך כדקה
3. **ברירות המחדל המובנות של הנגן**

המשך המסמך בנוי לפי החלוקה הזו. רוב הלקוחות צריכים רק את תצורת הנגן.

## תצורת הנגן

את התצורה הנוכחית שלכם אפשר לקרוא בכתובת `https://player.viewstream.co.il/player/config/<tenant>.json`, ותצורה בעלת שם
בכתובת `/player/config/<tenant>/<name>.json`. ב-Studio אפשר גם לשייך תצורה לערוץ, למדור בספרייה או לסרטון בודד.

## מאפייני תגית הנגן

המאפיינים האלה נכתבים על תגית ה-`embed.js` וגוברים על התצורה. ברשימה הזו, המאפיין `data-idle-ms` קובע את האפשרות
`idleMs`.

### מקור

| מאפיין | משמעות |
|---|---|
| `data-src` | כתובת מקור של HLS, של MP4 או של פורמט אחר |
| `data-tenant` | ה-slug של הארגון שלכם. אחרת הוא נלקח מהכתובת |
| `data-config` | תצורת נגן בעלת שם |
| `data-target` | בורר CSS של האלמנט שהנגן ימלא. אחרת הנגן מופיע במקום שבו נמצאת התגית |
| `data-id` | מזהה (id) לתיבת הנגן |
| `data-mode="tile"` | אריח תצוגה מקדימה מושתק במקום נגן מלא |
| `data-trigger` | אריח: `auto`, `hover` או `visible` |

### מראה וגודל

| מאפיין | משמעות |
|---|---|
| `data-skin` | סקין מובנה או מזהה מתוך ספריית הסקינים |
| `data-theme` | `auto`, `light`, `dark` |
| `data-lang` | `he`, `en`, `ru`, `ar` |
| `data-accent`, `data-accent-fg`, `data-focus` | הצבע הראשי, צבע הטקסט שמעליו וטבעת המיקוד |
| `data-aspect` | `16:9`, `4:3`, `1:1`, `9:16`, `21:9` |
| `data-width` | רוחב מרבי בפיקסלים |
| `data-skin-menu="1"` | מאפשר לצופים להחליף סקין בתפריט ההגדרות |
| `data-label` | תווית לקורא מסך |

### ניגון

| `data-epg-card-position` | `bottom-start`, `bottom-end`, `top-start`, `top-end` |
| `data-channel-name` | שם הערוץ על הכרטיס |
| `data-time-zone` | שם אזור הזמן לשעון ולשעות התוכניות |

### רשימות ואובייקטים

אלה נכתבים בתוך `data-options` כ-JSON.

| מפתח | פורמט |
|---|---|
| `sources` | `[{"src": "...", "type": "...", "height": 720, "label": "720p"}]` |
| `tracks` | `[{"src": "...vtt", "srclang": "he", "label": "עברית", "default": true}]` |
| `chapters` | `[{"start": 0, "title": "..."}]` |
| `thumbnails` | `{"sprite": "...jpg", "interval": 1, "width": 160, "height": 90, "cols": 10}` |
| `content` | `{"kind": "asset", "id": "..."}`. מציין מה מתנגן כשהכתובת אינה מציינת זאת. הערך של `kind` הוא `asset`, `clip` או `programme` |
| `meta` | `{"title": "...", "description": "...", "subtitle": "..."}` לכרטיס הכותרת |
| `epg` | `{"tenant": "...", "channel": "..."}`, או `epgUrl` עם כתובת של לוח שידורים |
| `shareUrl` | העמוד שכפתור השיתוף משתף |
| `titleCard` | `false`: בלי כרטיס כותרת |
| `doubleTapSkip` | `false`: בלי דילוג בהקשה כפולה במסכי מגע |
| `tapForSound` | `false`: בלי ההצעה "הקישו להפעלת קול" בניגון אוטומטי |
| `timeshift` | `false`: בלי חזרה אחורה אל תוך ההקלטה בחלונות שידור חי קצרים |
| `hour12` | `true`: שעון של 12 שעות. ברירת המחדל היא שעון של 24 שעות |
| `configDoc` | תצורת נגן חלקית שמתמזגת מעל התצורה שפורסמה |

## מקלדת

| מקש | פעולה |
|---|---|
| רווח, `k` | ניגון או השהיה |
| ← ו-→ | 5 שניות אחורה או קדימה |
| `j` ו-`l` | 10 שניות אחורה או קדימה |

| `m` | השתקה |
| `f` | מסך מלא |
| `c` | הפעלה או כיבוי של הכתוביות |
| `p` | תמונה בתוך תמונה |
| `t` | מצב קולנוע, כשהוא מופעל |
| `i` | לוח נתונים טכניים, כשהוא מופעל |

## אירועים

האירועים העיקריים של תגית הנגן מתוארים במסמך [EMBED.he.md](EMBED.he.md). האירוע `vs:ready` נותן לכם את הנגן, שהוא נגן
Video.js, ולכן כל אירועי Video.js הרגילים פועלים. הנגן מוסיף את האירועים שבטבלה. הפרטים שלהם עשויים להשתנות בין גרסאות.

| אירוע | מתי |
|---|---|
| `vs:qualitychange`, `vs:captionchange`, `vs:audiochange` | הצופה החליף איכות, כתוביות או שמע |
| `vs:skinchange`, `vs:themechange` | הסקין או המראה השתנו |
| `vs:menuopen`, `vs:cast`, `vs:resume` | תפריט נפתח, מצב השידור למסך השתנה, או שהניגון המשיך מנקודה שמורה |
| `vsdeny` | ה-CDN דחה את הניגון, למשל בגלל טוקן, מיקום גאוגרפי או חסימת שידור (blackout) |
| `vsreconnect`, `vstokenrefresh` | הנגן התחבר מחדש, או חידש את הטוקן שלו |
| `vs:drmunavailable` | ניתן מקור עם DRM, אבל תמיכת ה-DRM לא נטענה |
| `adstart`, `adend`, `adskip`, `adclick`, `quartile` | התקדמות הפרסומת |

## קריאת מידע מהנגן מתוך העמוד שלכם

קראו מידע מהנגן. אל תשנו מהעמוד שלכם את המקור שלו או את ההגדרות שלו.

| קריאה | מחזירה |
|---|---|
| `window.VSEmbed` | `{version, players}`: כל נגן שהטוען יצר |
| `player.vs.qualities()`, `player.vs.qualityLabel()` | האיכויות הזמינות, והאיכות הנוכחית |
| `player.vs.captionTracks()`, `player.vs.captionIndex()` | רצועות הכתוביות, והרצועה הנוכחית |
| `player.vs.audioTracks()` | רצועות השמע |
| `player.vs.skin()` | הסקין הנוכחי |
