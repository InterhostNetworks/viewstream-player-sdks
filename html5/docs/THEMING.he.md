# עיצוב הנגן

כתבו כל כלל תחת `.video-js.vs-theme.my-theme`. כך ה-CSS שלכם אינו נוגע בשאר העמוד, והוא גובר על הכללים של הנגן עצמו
בלי `!important`.

התחילו מהמשתנים. הם משנים את רוב הנגן בבת אחת וממשיכים לפעול גם כשאנחנו מעדכנים אותו. השתמשו בדריסה של מחלקה (class)
רק כשמשתנה אינו יכול לעשות את מה שאתם צריכים.

## משתנים

| משתנה | על מה הוא שולט | ברירת המחדל של הנגן |
|---|---|---|

| `--vs-accent-ink` | סמל או טקסט שמעל הצבע הראשי. שמרו על ניגודיות של 4.5:1 לפחות | `#04121B` |
| `--vs-ui` | סמלים וטקסט | `#fff` |
| `--vs-ui-dim` | טקסט משני | `rgba(255,255,255,.72)` |
| `--vs-panel` | תפריטים ולוחות | `rgba(12,16,22,.92)` |
| `--vs-border` | גבולות הלוחות | `rgba(255,255,255,.14)` |
| `--vs-hover` | רקע במעבר עכבר | `rgba(255,255,255,.08)` |
| `--vs-scrim-1`, `--vs-scrim-2` | ההצללות שמאחורי הפקדים | כהה, שקוף למחצה |
| `--vs-rail` | המסילה של פס ההתקדמות | `#BDBDBD` |
| `--vs-buf` | החלק שכבר נטען בפס ההתקדמות | `#636363` |

הנגן קובע בעצמו כמה משתנים בזמן הריצה, כמו `--vs-cb-h`, `--vs-tb-h`, `--vs-lb` והערכים `--vs-logo-*`. אל תקבעו אותם.

### הצבע הראשי בסביבת הייצור

הצבע הראשי שבתצורת הנגן שלכם גובר על `--vs-accent`, על `--vs-accent-ink` ועל `--vs-volfill`, וצבע המיקוד גובר על
`--vs-ring`. סביבת העבודה מנקה את הצבע הראשי, ולכן העיצוב שלכם מוצג בדיוק כפי שנכתב. כשאתם מחזירים את העיצוב, ספרו לנו
מהם הצבעים הסופיים ונעדכן את התצורה שלכם בהתאם.

### מראה בהיר ומראה כהה

המראה הכהה הוא בלוק המשתנים הראשון. המראה הבהיר הוא הבלוק של `.video-js.vs-theme.vs-light.my-theme`. הנגן מוסיף את
`vs-light` כשהמראה הבהיר בשימוש, ולכן עצבו את שניהם.

### גופנים

קבעו `font-family` על `.video-js.vs-theme.my-theme`. ארחו את קובצי הגופן כפי שמתואר בקובץ README.

## מצבים

הנגן מוסיף את המחלקות האלה לאלמנט הראשי שלו. השתמשו בהן כדי לעצב כל מצב.

| מחלקה | משמעות |
|---|---|
| `vjs-playing`, `vjs-paused`, `vjs-waiting` | מתנגן, מושהה, טוען |
| `vjs-user-active`, `vjs-user-inactive` | הפקדים מוצגים, הפקדים מוסתרים |
| `vjs-fullscreen` | מסך מלא |
| `vs-ad-playing` | פרסומת מתנגנת |
| `vs-menu-open` | תפריט פתוח |
| `vs-has-pbar`, `vs-epg-card-on`, `vs-epg-noprog` | שידור חי: פס התוכנית מוצג, הכרטיס מוצג, אין מידע על התוכנית |
| `vs-live-only` | שידור חי בלי אפשרות לחזור אחורה |
| `vs-reconnecting`, `vs-blocked` | מתחבר מחדש, הניגון נדחה |
| `vs-casting`, `vs-airplay-on` | שידור למסך טלוויזיה |
| `vs-content-rtl`, `vs-lang-he` | תוכן בעברית או בשפה אחרת שנכתבת מימין לשמאל |
| `vs-w-xs`, `vs-w-s` | נגן צר מאוד ונגן צר. השתמשו בהן במקום media queries, כי הנגן יכול להיות קטן גם על מסך רחב |
| `vs-cc-large`, `vs-cc-high-contrast` | סגנון הכתוביות שהצופה בחר |

לכל דבר אחר, חפשו בקובץ `reference/vs-vjs.reference.css`.

## כללים ששומרים על הנגן תקין

- **מימין לשמאל:** השתמשו ב-`inset-inline-start`, ב-`margin-inline-end` ובמאפיינים דומים, ולא ב-`left` וב-`right`.
  פס ההתקדמות הוא היוצא מן הכלל, כי הוא תמיד מתקדם משמאל לימין.
- **אל תזיזו את הווידאו ואל תשנו את גודלו:** אל תיגעו ב-`.vjs-tech` וב-`.vs-ad__video`, ואל תוסיפו להם פילטרים.
- **שמרו על טבעת המיקוד:** לעולם אל תשתמשו ב-`outline: none` בלי תחליף גלוי.
- **אזורי מגע:** שמרו על כפתורים בגודל 40 × 40 פיקסלים לפחות בטלפונים.
- **הימנעו מרוחב קבוע:** הנגן פועל בכל גודל, מאריח קטן ועד מסך מלא.
- **הימנעו מ-`!important`:** הוא עלול לשבור מצבים שהנגן צריך, כמו הסתרת הפקדים בזמן פרסומת.
- **שמות פנימיים:** שמות המחלקות עשויים להשתנות בין גרסאות הנגן, ולכן המשתנים הם הבחירה הבטוחה יותר.
