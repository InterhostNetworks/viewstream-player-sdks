# ViewStream Player SDKs

Kits for putting the ViewStream player on your website or in your app.

| SDK | Folder | Start here |
|---|---|---|
| HTML5 Player SDK: the web player, its options, and a workbench for designing your own skin | [`html5/`](html5/) | [English](html5/README.md), [עברית](html5/README.he.md) |

More SDKs will be added here as they are released.

## Using this repository

- Download a kit with **Code → Download ZIP**, or clone the repository.
- Each kit has its own `README` and `VERSION` file. Releases are tagged per kit, for example `html5-v1.0.0`.
- The player itself is not in this repository. The kits load it from `player.viewstream.co.il`.

## Questions and changes

This repository is published from ViewStream's own source, and each release replaces the files here. Please open an
issue or talk to your ViewStream contact instead of sending a pull request, because a pull request merged here would be
overwritten by the next release.

See [LICENSE](LICENSE). The kits are for ViewStream customers, to design and integrate the ViewStream player.

# ערכות הפיתוח לנגן של ViewStream

ערכות להצבת הנגן של ViewStream באתר או באפליקציה שלכם.

| ערכה | תיקייה | מתחילים כאן |
|---|---|---|
| ערכת הפיתוח לנגן HTML5: נגן הרשת, האפשרויות שלו וסביבת עבודה לעיצוב סקין משלכם | [`html5/`](html5/) | [עברית](html5/README.he.md), [English](html5/README.md) |

ערכות נוספות יתווספו לכאן כשישוחררו.

## איך משתמשים במאגר

- מורידים ערכה בלחיצה על **Code ← Download ZIP**, או משכפלים את המאגר.
- לכל ערכה יש קובץ `README` וקובץ `VERSION` משלה. הגרסאות מתויגות לכל ערכה בנפרד, למשל `html5-v1.0.0`.
- הנגן עצמו אינו נמצא במאגר הזה. הערכות טוענות אותו מ-`player.viewstream.co.il`.

## שאלות ושינויים

המאגר מתפרסם מתוך קוד המקור של ViewStream, וכל גרסה מחליפה את הקבצים שכאן. פתחו issue או פנו לאיש הקשר שלכם
ב-ViewStream במקום לשלוח pull request, כי pull request שימוזג כאן יידרס בגרסה הבאה.
